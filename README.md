# Twitch Monitor - 初コメ・イベント検知スマホビューア

Twitch配信者向けに、PCを介さずスマホ単体でリアルタイムにイベント（初見コメント、ビッツ、チャンネルポイント）を検知・確認できる軽量な静的Webアプリケーションです。

## 特徴
*   **完全サーバーレス:** Node.jsやデータベース等のバックエンドは一切不要。GitHub Pages等の静的ホスティングサービスにアップロードするだけで動作します。
*   **スマホ特化UI:** 縦画面で見やすいカード型レイアウトを採用。
*   **イベントの視認性向上:**
    *   🔵 初コメ（通常） / 🟠 初コメ（レイド経由） / 🚨 レイド通知
    *   🟣 ビッツ（Cheer金額とメッセージ） / 💎 Bitsバッジ達成通知
    *   🟢 チャンネルポイント（交換対象とテキスト） / ✨ ハイライトメッセージ
    *   🩵 フォロー通知（チャンネルフォロー時）
    *   🩷 サブスク通知（連続月数・Prime等詳細表示） / 🎁 コミュニティギフト / 💝 恩送り
    *   📢 アナウンスメント（重要度カラー対応） / ❤️ チャリティ寄付
    *   💬 通常コメント（リプライ元表示、メンション強調、自己紹介バッジ対応）
*   **高度なチャット体験:** アニメーションエモート（GIF）やチアモート画像のアライン表示に自動対応。
*   **自動接続:** 一度ログインすれば、ブラウザを閉じても有効期限内（localStorage）は自動で再接続・監視を再開します。
*   **機能の充実:** `!test` コマンドによる表示テスト機能、文字の拡大縮小、画面の自動スクロール、カラー説明のヘルプ機能などを搭載。

## 使い方

1.  本アプリの公開URLにスマホやPCのブラウザからアクセスします。（例: `https://paru910.github.io/twitch-monitor/`）
2.  画面中央の **「Twitchで連携」** ボタンをタップします。
3.  Twitchの認証画面が表示されるので「許可 (Authorize)」します。
4.  元の画面に戻り、上部のステータスが **緑色の「接続完了」** になれば準備完了です！
    * ※以降は、監視対象の配信で初コメやビッツなどが発生するたびに画面にカードが追加されていきます。
    * 一度連携すれば、認証状態はブラウザに保存されるため、次回からはURLを開くだけで自動で繋がります。

## 技術スタック
*   **HTML5 / Vanilla JavaScript**
*   **Tailwind CSS (CDN)** - スタイリング
*   **Twitch EventSub (WebSocket)** - リアルタイムイベント監視
*   **Twitch API (Helix)** - ユーザー情報の取得
*   **OAuth Implicit Grant Flow** - フロントエンド単体での認証

## 注意事項 / 制約
*   本アプリはTwitchの仕様上、**`http://localhost` または `https://` で始まるURL**からでないとOAuthによる認証機能が正常に動作しません（PCのローカルファイルを直接ブラウザで開く `file:///.../index.html` では動きません）。
*   取得したアクセストークンはブラウザの `localStorage` に保存されます。共有の端末などをご使用の場合はご注意ください。
*   ブラウザのタブがバックグラウンドに回った際や、スマートフォンのスリープ中は、OSの仕様によりWebSocket通信が切断される・遅延する場合があります。配信中はなるべくアプリを最前面で表示し続けることを推奨します。
