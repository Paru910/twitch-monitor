# Twitch Monitor - 初コメ・イベント検知スマホビューア

Twitch配信者向けに、PCを介さずスマホ単体でリアルタイムにイベント（初見コメント、ビッツ、チャンネルポイント）を検知・確認できる軽量な静的Webアプリケーションです。

## 特徴
*   **完全サーバーレス:** Node.jsやデータベース等のバックエンドは一切不要。GitHub Pages等の静的ホスティングサービスにアップロードするだけで動作します。
*   **スマホ特化UI:** 縦画面で見やすいカード型レイアウトを採用。
*   **イベントの視認性向上:**
    *   🔵 初コメ（これまでコメントしていなかったユーザーからのチャット）
    *   🟣 ビッツ（Cheer金額とメッセージ）
    *   🟢 チャンネルポイント（交換された報酬名と入力テキスト）
*   **ワンタップ既読:** 表示されたカードはタップするだけで画面から消去できます。
*   **自動接続:** 一度ログインすれば、ブラウザを閉じても有効期限内（localStorage）は自動で再接続・監視を再開します。

## 使い方（配信者向け）

### 準備: Twitch Client ID の取得
本アプリを自身の環境で動かすには、Twitch APIを利用するための `Client ID` が必要です。

1.  [Twitch Developer Console](https://dev.twitch.tv/console/apps) にログインします。
2.  「アプリケーションの登録 (Register Your Application)」をクリックします。
3.  以下の情報を設定して作成します：
    *   **名前:** （任意のアプリ名）
    *   **OAuth リダイレクト URL:** このアプリを公開するURL（例: `https://[あなたのID].github.io/twitch-monitor/`）。
    *   **カテゴリ:** アプリケーションチャットボット（またはその他）
4.  作成後、「管理 (Manage)」画面を開き、表示されている **Client ID** をコピーします。

### セットアップと起動・ログイン
1.  このリポジトリをFork、またはダウンロードして、ご自身のGitHubリポジトリ（GitHub Pages）等へ公開します。
2.  公開したURL（登録したリダイレクトURL）へスマホのブラウザでアクセスします。
3.  初回のみ、画面の入力欄に先ほど取得した **Client ID** を入力します。
4.  「Twitchで連携」ボタンをタップします。
5.  Twitchの認証画面が表示されるので「許可 (Authorize)」します。
6.  元の画面に戻り、上部のステータスが **緑色の「接続完了」** になれば準備完了です！
    * ※以降は、ご自身の配信で初コメやビッツなどが発生するたびに画面にカードが追加されていきます。
    * 一度連携すれば、Client IDと認証状態はブラウザに保存されるため、次回からは自動で繋がります。

## 技術スタック
*   **HTML5 / Vanilla JavaScript**
*   **Tailwind CSS (CDN)** - スタイリング
*   **Twitch EventSub (WebSocket)** - リアルタイムイベント監視
*   **Twitch API (Helix)** - ユーザー情報の取得
*   **OAuth Implicit Grant Flow** - フロントエンド単体での認証

## 注意事項 / 制約
*   本アプリはTwitchの仕様上、**`http://localhost` または `https://` で始まるURL**からでないとOAuthによる認証機能が正常に動作しません（PCのローカルファイルを直接ブラウザで開く `file:///.../index.html` では動きません）。
*   取得したアクセストークンはブラウザの `localStorage` に保存されます。共有の端末などをご使用の場合はご注意ください。
*   ブラウザのタブがバックグラウンドに回った際や、スマートフォンのスリープ中は、OSの仕様によりWebSocket通信が切断される・遅延する場合があります。配信中はなるべくアプリを最前面で表示し続けることを推奨します。
